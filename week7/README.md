The plot suggests that in the data from the third replicate of the LFC-Fe section might have been swapped with the data from the first replicate from the Fe section. Replicates are always expected to cluster together and the accidental swapping of the labels would explain this mismatch perfectly.

PC1 usually captures variation at the technical level as well as biological differences like tissue type or developmental stage. In this case it seems like the cells types are also in the same order in the PCA plot as they are spatially organized in the midgut.
